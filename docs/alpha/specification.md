# alpha: specification

## Value proposition

alpha puts a development process into a project for Claude Code to work under: principles, docs, Claude Code and git hooks, CI, and a test setup per component that passes from the first commit. Each principle is checked by a hook or by a reviewer agent before a change reaches main.
