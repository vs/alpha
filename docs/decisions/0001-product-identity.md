# 0001. Product identity

Date: 2026-11-12
Status: accepted
Kind: product

## Context

alpha is an existing Claude Code plugin being adopted; its README states what it does. It serves developers who want agents held to engineering principles in new and existing repos.

## Decision

Name alpha (slug alpha), for developers building with Claude Code; requirements R1 (interview), R2 (generate), R3 (enforce), R4 (adopt), R5 (extend), R6 (recipes), R7 (user layer). MIT, keeping the repo LICENSE; domain jargon on.

## Consequences

Features outside R1-R7 need a new requirement first. The glossary and One vocabulary principle apply to code, docs and skills.
